四、关键参数解释
===============================================================================

NPC标识:
  * npcID 0 = 玩家角色(AMING)
  * npcID 2 = 袁思阙(敌方视角)
  * npcID 3 = 袁思阙(中立/友好视角)
  * npcID 4 = 旁白/叙述者

关系等级:
  * 初始: 0
  * 目标: 5(最高)
  * 提升路径: 0→2(任务激活)→3(对话)→4(追加对话)→5(婚礼路线)

激活条件语法示例:
  * "2/NPC关系等级/>=/2/0//3/2/0/WJ10981"
    = NPC(WJ10981)关系等级>=2
  * "3/NPC状态/=/已登场/3/0/0/WJ10981"
    = NPC(WJ10981)已登场
  * "1/玩家性别/=/男"
    = 玩家为男性

事件格式:
  * eventType=4: 对话触发事件
  * eventType=24: 关系变化 (option=7为对话关系加成)
  * eventType=19: 战斗触发
  * eventType=31: NPC配置 (eventNPC="2/2/0//1/"为敌方)
  * eventType=404: 战斗奖励分配
  * eventType=505: 结婚仪式 + 公式应用
  * eventType=30: 任务/目标完成

战斗配置:
  * scene=80: 演武场场景
  * canAuto=0: 禁止自动战斗(手动操作)
  * source=1: 事件触发型战斗

七、注意事项
===============================================================================

1. 本事件仅在以下条件下激活:
   - 玩家为男性角色
   - 与袁思阙关系等级≥2且≤5
   - 袁思阙未婚且已登场

2. 武斗场景需要在演武场(scene 80)进行

3. 对话分支只有特定选项会触发下一步:
   - "深入交流" ✓
   - "告辞" = 事件结束
   - "提议比武" ✓
   - "就此告别" = 事件结束

4. 战斗胜利是触发婚礼的必要条件

5. 婚礼后系统会自动设置夫妻关系(couple字段)
